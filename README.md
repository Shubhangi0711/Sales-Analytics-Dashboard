# 📊 Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard** built using Python that analyzes over **10,000+ sales records** to uncover business insights and track key performance indicators (KPIs) such as **Revenue, Average Order Value (AOV), and Sales Trends**.

---

## 🚀 Project Overview

This project focuses on transforming raw sales data into meaningful insights through an interactive dashboard. It helps in understanding business performance, identifying trends, and making data-driven decisions.

---

## 🛠️ Tech Stack

- **Python**
- **Pandas** – Data cleaning & analysis
- **Streamlit** – Interactive dashboard UI
- **SQLite** – Lightweight database for structured storage
- **Matplotlib / Plotly** – Data visualization

---

## 📌 Key Features

- 📈 Real-time interactive dashboard
- 💰 Revenue tracking and breakdown
- 🧮 Average Order Value (AOV) analysis
- 📊 Sales trend visualization over time
- 🔍 Filterable insights (region, product, time period)
- 🗄️ SQLite integration for efficient data handling

---

## 📂 Dataset

- Contains **10,000+ sales transactions**
- Includes fields like:
  - Order ID
  - Product Name
  - Category
  - Revenue
  - Quantity
  - Date
  - Region

---

## 🧠 Key Insights Generated

- Top-performing products and categories  
- Revenue contribution by region  
- Monthly and weekly sales trends  
- Customer purchase behavior patterns
